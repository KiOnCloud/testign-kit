# Phase 3: Console UI shell, i18n and screens

## Goal

The browser console with Kestrel styling and vi, en and ja chrome: Tickets, Report, Trace,
Templates (with registration), Scout cache and Settings, built on the read API.

## Context

- Mockup: https://claude.ai/artifact/FbwXMaek4XshNT2nPdpkTB (six screens, language switcher, light and dark).
- Kestrel source: https://claude.ai/artifact/8zVwRX2YRdzPjEyPSVaB8i, version `1795001967-49ce` (`project/tokens.json`, `project/components/bundle.css`). Its `tokens.css` is generated by the design system page and is not published; the canvas copy (`project/ds/kestrel/tokens.css` of the mockup) is the generated version with the Japanese font stack.
- Content rule: chrome follows the UI language; report content, quotes, template headers and wiki text stay as written.

## Requirements

- [ ] No build step: `index.html` loads `main.mjs` as a module; every file is served from the phase 1 manifest.
- [ ] CSP-clean: no inline `style` attributes, inline scripts or event-handler attributes; all styling through classes in `app.css` and Kestrel classes. Data goes into the DOM through `textContent` and attributes only.
- [ ] The token is read from `#t=` once, kept in `sessionStorage`, removed from the URL with `history.replaceState`, and sent as `X-Testign-Token`. A 403 shows "open the console from `/testign:console` again".
- [ ] i18n: `i18n/vi.json`, `en.json`, `ja.json` with the same flat keys; `t(key, params)` with `{name}` interpolation; a missing key falls back to vi, then to the key. `<html lang>` follows the choice.
- [ ] Language and theme are stored in `localStorage` (`testign.uiLang`, `testign.theme`) inside try/catch; defaults: language from `navigator.languages` (ja → ja, en → en, else vi), theme light.
- [ ] Dates show as ISO `YYYY-MM-DD`; numbers in tables use tabular figures.
- [ ] Fonts self-hosted: Inter variable and JetBrains Mono 400/500, subsets latin, latin-ext and vietnamese, with `unicode-range`; Japanese uses the system stack (Hiragino, Yu Gothic UI, Meiryo).
- [ ] Layout works from 390 px to 1440 px: sidebar stacks, toolbars wrap, wide tables scroll inside their box; no horizontal page scroll.
- [ ] Keyboard: every control reachable by Tab with a visible focus ring; `Ctrl/⌘+K` opens a palette that navigates to screens and tickets; `Esc` closes the palette and the split panel.

## Tasks & Steps

1. Vendor Kestrel and the fonts; write `LOCK.json`; add the drift test (vendored sha256 equals `LOCK.json`).
2. `dom.mjs`: `h(tag, attrs, children)` that sets text with `textContent` and refuses `on*` and `style` attributes.
3. Shell: sidebar (nav, counts, language switcher, agent status placeholder), top bar, router on `location.hash` (`#/tickets`, `#/tickets/DEMO-1`, `#/tickets/DEMO-1/trace`, `#/templates`, `#/cache`, `#/settings`).
4. i18n module and the three dictionaries; every view takes strings from `t()` only.
5. Views in the order Tickets, Report, Trace, Templates, Scout cache, Settings, each with loading, empty and error states.
6. Palette; focus management for the split panel and dialogs.
7. Tests and CI.

## Verification

- `node --test scripts/testign/console/ui/tests/` — i18n key parity and no empty values across vi, en, ja; interpolation; fallback; `h()` escapes text and refuses `on*`/`style`; router parsing; ISO date formatting.
- `python -m pytest tests/test_console_ui_assets.py -v` — key parity (also on CI runners where Node is skipped), no `style=` or `on…=` attribute in any `.html`/`.mjs`, no `innerHTML` in any `.mjs`, vendored files match `LOCK.json`, every font file has a licence beside it.
- `TESTIGN_E2E=1 python -m pytest tests/e2e -v` — loads each screen against fixture data in vi, en and ja at 390 and 1440 px; asserts no console CSP violation, no horizontal page scroll, and that switching language changes a chrome label while a report cell's text stays the same.

## Success Criteria

Acceptance criterion 6 passes; each screen of the mockup that belongs to this phase renders from live data in all three languages.

## Risk Assessment

- Mixed Inter and system Japanese faces look uneven in one line. Signal: the e2e screenshot review in ja. Response: accept for an internal tool, or ship Noto Sans JP subsets later (several MB); decide at review, not now.
- Japanese or English labels overflow fixed widths. Signal: the no-horizontal-scroll assertion or a clipped label in screenshots. Response: fix the layout; never shorten the translation silently.

## Security Considerations

- The token lives in `sessionStorage` of the console's own origin only; it is never written to `localStorage` or logs.
- Report text from customers is shown with `textContent` only, so a report cannot inject markup.
